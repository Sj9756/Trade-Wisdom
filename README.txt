TRADE WISDOM SOLUTIONS — SPLIT HTML/CSS/JS VERSION

Files:
- index.html  -> page structure/content
- style.css   -> all styling/responsive design/animations
- script.js   -> menu, reveal animations, year, WhatsApp form
- logo.png    -> company logo

All files must stay in the same folder.

To test:
1. Open index.html in a browser.
2. The website should load from the local files.
3. Upload all four files to public_html on MilesWeb.

No build tool, npm, React, or backend is required.
